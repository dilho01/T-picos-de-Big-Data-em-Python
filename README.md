# 🌸 Classificador de Flores Íris

Este projeto é uma aplicação em Python com interface gráfica que utiliza **Machine Learning** para classificar flores Íris com base em suas medidas. O modelo foi treinado com o famoso **Iris Dataset** usando o algoritmo de **Árvore de Decisão (Decision Tree)**.

![Badge](https://img.shields.io/badge/Python-3.10-blue.svg) ![Badge](https://img.shields.io/badge/Tkinter-GUI-orange) ![Badge](https://img.shields.io/badge/Scikit--Learn-ML-yellowgreen)

## 🚀 Funcionalidades

- Interface gráfica amigável desenvolvida com `Tkinter`
- Entrada de dados manuais: comprimento e largura das sépalas e pétalas
- Classificação automática com modelo treinado em `scikit-learn`
- Validação de dados com mensagens de erro e sucesso
- Exibição do resultado da classificação ao usuário

## 📊 Dataset

Utilizado o [Iris Dataset](https://archive.ics.uci.edu/ml/datasets/iris), amplamente usado para problemas de classificação.
